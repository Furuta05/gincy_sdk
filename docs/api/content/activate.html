Проверяет одну запись и делает её активной, не трогая модуль.

Зачем это нужно. Это путь файла из gincy_content и путь MOD:LoadContent. Сломанная новая версия не затирает старую.

Где это встречается на сервере

  • Обход папки после старта.
  • Горячая правка урона.

Синтаксис

Gincy.Content.Activate("combat.skill", "fireball", {
    name = "Fireball",
    damage = 45,
    cooldown = 4
}, "combat", { file = "gincy_content/combat/skill/fireball.lua", origin = "content" })

Последняя таблица — сведения о файле, не поля навыка.

Что означает каждая часть

  • kind и id — Тип и запись.
  • definition — Таблица из файла.
  • owner — Должен совпасть с владельцем типа.
  • origin — content или dev. Если dev уже занял id, файл из gincy_content пропускается и Activate возвращает true, "skipped".
  • depends — Список строк тип/id, если такого поля нет в схеме.

Что возвращается

true и экземпляр, либо true и строка skipped, либо false и ошибка. Экземпляр — внутренная таблица. Игровому коду для вызова поведения нужен Call или прокси, не поля экземпляра напрямую.

Что происходит после вызова

Поля проверяются, функции отделяются, зависимости ищутся, prepare вызывается. Только потом запись подменяется. Старые задачи этого id отменяются после успеха. Человеческий текст ошибки кладётся в Failures: поле, что ждали, что пришло, файл.

Перезагрузка и выгрузка

Не перезагружает модуль. Release экземпляра при успехе новой версии снимает только задачи этого навыка.

Ограничения

  • Файл Lua контента не видит Gincy: среда пустая.
  • uses перечисляет возможности, которых нет у типа — запись отклоняется, кроме имён Schedule и After, они особые.
  • depends на самого себя пропускается.

Рядом обычно вызывают

  • Куда класть файл — Пути папок.
  • Call — Как вызвать cast.

Плохой cooldown

Gincy.Content.Activate("combat.skill", "fireball", {
    name = "Fireball",
    damage = 45,
    cooldown = "fast"
}, "combat", { file = "gincy_content/combat/skill/fireball.lua" })

Вернётся неудача. Если раньше фаербол уже был с числом, игроки продолжат бить старым уроном. В gincy content inspect будет поле cooldown, ожидание number и текст fast.
