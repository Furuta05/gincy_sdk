Читает и пишет одно значение по полному имени пространства и ключу.

Зачем это нужно. MOD:Storage подставляет пространство сам. Прямой вызов нужен, если имя уже собрано, например stamina.players. Ответ всегда в callback. return данных нет.

Где это встречается на сервере

  • Чужой административный скрипт читает ключ модуля.
  • Понять коды ошибок без обёртки.

Синтаксис

Gincy.Storage.Get("stamina.players", "76561190000000000", function(ok, err, value)
    print(ok, value and value.stamina)
end)
Gincy.Storage.Set("stamina.players", "76561190000000000", { stamina = 40 }, function(ok, err, value)
    print(ok)
end)

Пространство должно быть идентификатором. Его создаёт Register или MOD:Storage.

Что означает каждая часть

  • namespace — Полное имя, не короткое players.
  • key — Идентификатор ключа.
  • value — Укладывается в JSON не длиннее 16384 символов.
  • коды — INVALID_KEY, INVALID_VALUE и коды соединения базы. Пароль в них не пишется.

Аргументы

АргументТипОбязательныйПо умолчаниюЧто передавать
namespaceстрокаданетПравило идентификатора.
keyстрокаданетТо же правило.
valueлюбоеда для SetнетПри непустой схеме — таблица нужных типов.
callbackfunctionда для Getнет для SetСигнатура ok, err, value.

Что возвращается

Ничего в момент вызова.

Что происходит после вызова

SQL уходит в пул. При успехе Get отдаёт сохранённое значение, Set отдаёт то же значение, которое ты положил. При пустой таблице в базе value будет nil и ok может быть истиной: ключа просто нет.

Перезагрузка и выгрузка

Unregister снимает только описание схемы в памяти.

Ограничения

  • Не вызывай из Think.
  • Не жди результат присваиванием local x = Storage.Get. x будет nil всегда.
  • Транзакция — отдельная функция Gincy.Storage.Transaction со списком {sql, params} и таким же callback.

Рядом обычно вызывают

  • MOD:Storage — Короткие имена.
  • Diagnostics — Почему callback падает сразу.

Нет ключа

Gincy.Storage.Get("stamina.players", "76561190000000000", function(ok, err, value)
    local stamina = (ok and value and value.stamina) or 100
    print(stamina)
end)

Первый заход игрока печатает 100, потому что строки ещё нет и value пустой. Это не ошибка модуля. Ошибка — это ok равный false, тогда смотри err.code и не затирай стамину нулём.
