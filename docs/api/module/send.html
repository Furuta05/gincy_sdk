MOD:Send проверяет таблицу той же схемой, что MOD:Net, и отдаёт её в сеть Gincy. Кривую таблицу он не ставит в очередь.

Зачем это нужно. Сервер подтверждает выбор, присылает откат умения, обновляет число в меню.

Где это встречается на сервере

  • Сказать клиенту, какой навык принят.
  • Отказать, не отправляя мусор.

Синтаксис

MOD:Send("select_skill", ply, {
    skill = "fireball"
})

Короткое имя, игрок, таблица полей.

Что означает каждая часть

  • name — То же короткое имя, что в Net.
  • ply — Кому. На сервере это игрок.
  • data — Только объявленные поля. skill = "fireball" подходит под string.

Аргументы

АргументТипОбязательныйПо умолчаниюЧто передавать
nameстрокаданетНеизвестное имя даёт ошибку unknown net message, это именно error, не тихий false.
plyPlayerданетПолучатель для серверной отправки.
dataтаблицаданетПроверяется схемой. Лишнее поле — отказ.

Что возвращается

Если поля плохие: false и объект ошибки с кодом GINCY-NET-SCHEMA. Если поля хорошие: то, что вернёт сетевой слой. При успехе постановки в очередь это true.

Что происходит после вызова

Данные кодируются и встают в очередь отправки. Кадр сети уходит существующим транспортом Gincy, не отдельным net.Start на каждое поле. При нехватке бюджета очереди отправка вернёт false и код бюджета, пакет не будет частично принят как валидный.

Перезагрузка и выгрузка

После выгрузки модуля канал этого поколения снимается, необработанная очередь этого канала выбрасывается.

Ограничения

  • Send не объявляет канал. Сначала Net.
  • Направление MOD:Net — both, поэтому сервер может слать это имя. Низкоуровневый канал только c2s сервер слать не сможет.
  • Паролей и посторонних полей функция не добавляет.

Рядом обычно вызывают

  • MOD:Net — Объявление.
  • Gincy.Network.Send — Если нужно полное имя и приоритет.

Подтверждение

MOD:Net("select_skill", { skill = "string" })

MOD:Receive("select_skill", function(ply, data)
    local ok = MOD:Send("select_skill", ply, { skill = data.skill })
    if not ok then print("не ушло") end
end)

Игрок прислал навык. Сервер отправляет ту же строку обратно. Если в таблице случайно окажется damage = 10, Send вернёт false, потому что поля damage в схеме нет.
