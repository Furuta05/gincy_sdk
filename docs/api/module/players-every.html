MOD:PlayersEvery

Периодически обходит игроков одной задачей, а не таймером на каждого.

На 40 игроках сорок timer.Create легко устраивают всплеск. PlayersEvery держит одну задачу и сам берёт player.GetAll. Если включить spread, за один тик обрабатывается только пачка, остальные — следом.

Зачем это нужно. Реген выносливости, голод, проверка AFK, обновление статуса раз в четверть секунды.

Где это встречается на сервере

  • Выносливость всех игроков четыре раза в секунду.
  • Тяжёлый пересчёт статуса, который нельзя делать всем в один тик.

Синтаксис

MOD:PlayersEvery("regen", 0.25, function(ply)
    local value = ply:GetNWInt("Stamina", 0)
    if value < 100 then ply:SetNWInt("Stamina", value + 1) end
end)

Имя, интервал, функция. Функция вызывается отдельно на каждого подходящего игрока.

MOD:PlayersEvery("status", 1, { spread = true, batch = 20 }, function(ply)
    -- тяжёлая проверка одного игрока
end)

С пачкой. batch по умолчанию 20, даже если таблицу не передать. spread по умолчанию выключен: без него за один запуск обходятся все.

Что означает каждая часть

  • name — Строка задачи. Повтор с тем же именем заменяет задачу.
  • 0.25 — Секунды между полными обходами.
  • ply — Аргумент функции — один игрок из player.GetAll, у которого IsValid истинен.
  • spread — true режет список на пачки. Необязательно.
  • batch — Сколько игроков за один тик при spread. По умолчанию 20.

Что возвращается

Идентификатор задачи, строка.

Что происходит после вызова

Когда срок наступил, планировщик берёт текущий список игроков. Мёртвые и вышедшие пропускаются. С spread за тик идёт не больше batch игроков, курсор запоминается, остаток продолжится. Отдельного таймера на игрока нет.

Перезагрузка и выгрузка

Unload модуля отменяет задачу целиком. Выход одного игрока не удаляет общий обход: его просто не будет в следующем player.GetAll.

Ограничения

  • Не ставь ещё и MOD:Every(ply) на того же регена, иначе работа сделается дважды.
  • spread не гарантирует, что все игроки получат тик в одну и ту же секунду. Для точного одновременного удара spread не включай.
  • Функция не должна копить игроков в внешней таблице без проверки IsValid.

Рядом обычно вызывают

  • MOD:Every — Одна сущность или свой цикл.
  • scheduler — Среднее время задачи.

Выносливость

local MOD = Gincy.Module("stamina")

MOD:PlayersEvery("regen", 0.25, { spread = true }, function(ply)
    local value = ply:GetNWInt("Stamina", 0)
    if value < 100 then
        ply:SetNWInt("Stamina", value + 1)
    end
end)

Каждые 0,25 секунды начинается обход. За один тик обрабатывается до 20 игроков, остальные добираются следующими тиками, без нового таймера на человека. Игрок, который вышел, в список уже не попадёт. При перезагрузке stamina старый обход снимается.
