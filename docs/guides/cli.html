Команды начинаются с gincy. Ответ — текст с метками [OK], [WARN], [FAIL] и [--]. JSON печатается только если в команде есть --json. Пароль базы в текст не попадает.

Зачем это нужно. По ним видно, жив ли сервер, почему не встал модуль и что делать дальше. Подсказка часто начинается со слова Run:.

Где это встречается на сервере

  • После обновления файлов.
  • Когда база ещё не настроена.
  • Когда навык не загрузился.

Сборка package build в этой консоли только печатает напоминание вызвать внешнюю программу. Настоящая сборка описана на странице пакета.

Что означает каждая часть

  • --json — Просит машинный вывод. Без флага — текст.
  • --password-stdin — setup один раз читает data/gincy/runtime/storage.secret и удаляет этот файл. Пароль не обязан торчать в истории команды.
  • --cascade — disable сначала выключает модули, которые зависят от указанного.
  • storage setup — Спрашивает или принимает host, port, database, user, password, sslmode. Потом проверяет соединение, права, сохраняет конфиг, поднимает пул и гоняет миграции. Состояния в ответе: DISABLED, NOT_CONFIGURED, CONFIGURED, CONNECTING, READY, CONNECTION_FAILED, AUTH_FAILED, DATABASE_NOT_FOUND, MIGRATION_FAILED, NATIVE_UNAVAILABLE.
  • storage test — Отдельно показывает TCP, рукопожатие, вход, выбор базы, права и миграции, плюс версию сервера PostgreSQL и задержку, если они получены.
  • upgrade — status сравнивает сохранённое состояние data/gincy и версию программы. check только проверяет путь. run делает копию, миграцию и запись. Если программа старее сохранённого состояния, автоматический откат версии не выполняется.

Что возвращается

Команда печатает текст. Игровой возврат Lua-функции тут ни при чём: это консоль сервера.

Что происходит после вызова

setup не блокирует кадр ожиданием пароля в коде Lua: работа с базой идёт через уже существующий пул. create module создаёт два файла и возвращает путь. content inspect для сломанной записи показывает поле, ожидание, факт и файл, а машинный код ошибки остаётся в JSON.

Перезагрузка и выгрузка

Команды сами по себе хуки не снимают. reload и disable делают это через загрузчик.

Ограничения

  • Пустой список пакетов — это текст «пусто», а не сырой [].
  • Если база не нужна ни одному модулю, doctor помечает её как [--] not configured (not required), это не авария.
  • Если модуль просит базу, а её нет, модуль ждёт хранилище и подсказка ведёт на gincy storage setup.

Рядом обычно вызывают

  • Внешний gincy — Сборка .gmod.
  • Задача — Что показывает inspect.

Сломанный навык

gincy content inspect combat.skill fireball

В тексте будет поле cooldown, ожидание number, полученное fast и путь к lua-файлу. Модуль боя при этом остаётся загруженным.
