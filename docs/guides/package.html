.gmod — подписанный пакет одного модуля. Формат пакета сейчас 2. Старый пакет не отбрасывается только из-за того, что продукт стал 3.3.0: сравниваются диапазоны и числа ABI, если они записаны в пакете.

Зачем это нужно. Сервер принимает модуль из gincy_modules только после проверки подписи доверенным ключом из data/gincy/trust.

Где это встречается на сервере

  • Выдать серверу готовую боевую систему.
  • Проверить, что файл не подменили.
  • Собрать все папки в gincy_dev/modules разом.

Синтаксис

gincy package build <папка> --key signer.pem [--output файл.gmod]
gincy package build-all <папка-с-модулями> --key signer.pem [--output-dir garrysmod/gincy_modules]
gincy package inspect <файл.gmod> [--public-key trust.pem] [--json]
gincy package verify <файл.gmod> --public-key trust.pem
gincy package unpack <файл.gmod> --output <папка> [--public-key trust.pem]
gincy keygen <private.pem>
gincy identity <private.pem>

build — другое имя команды pack. Без --output сборка одного модуля пишет garrysmod/gincy_modules/id.gmod. build-all обходит подпапки, где есть manifest.lua.

Что означает каждая часть

  • --key — Путь к приватному ключу подписи. Обязателен для build, build-all, migrate.
  • --output — Куда писать один .gmod. Если не указан, используется gincy_modules.
  • --output-dir — Папка для build-all. По умолчанию garrysmod/gincy_modules.
  • --public-key — Чужой или свой публичный ключ для verify и inspect.
  • --json — inspect печатает JSON. Без флага текст человеческий.
  • --protected / --maximum / --drm — Режимы закрытия. Отдельная страница.
  • keygen — Создаёт пару ключей подписи в указанный pem.
  • identity — Ключ личности сервера. Это не ключ подписи модуля.

Что возвращается

Успех печатает путь и размер. Ошибка печати — код вроде GINCY-PKG-SIGNATURE-INVALID.

Что происходит после вызова

Исходная папка не меняется. Новый .gmod заменяет файл с тем же именем в папке назначения, если ты указал тот же путь.

Перезагрузка и выгрузка

Уже стоящий на сервере пакет обновляется, когда ты заменяешь файл и перезагружаешь модуль или карту. Сама команда build сервер не перезагружает.

Ограничения

  • Паролей базы в пакете нет.
  • unpack не вытащит закрытый исходник, если подписанная политика это запрещает: код GINCY-PKG-UNPACK-DENIED.
  • migrate поднимает старый контейнер до формата 2 как open. Закрытие после этого делается новой сборкой из исходников.

Рядом обычно вызывают

  • Режимы защиты — open, protected, maximum.
  • Команды карты — gincy package install.

Один модуль

gincy package build garrysmod/gincy_dev/modules/stamina --key signer.pem

Возьмёт manifest и lua-файлы папки, подпишет их ключом и положит garrysmod/gincy_modules/stamina.gmod. Папка stamina на месте.
