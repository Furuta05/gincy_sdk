По умолчанию сборка open: файлы модуля лежат в пакете так, что сервер их компилирует как обычный Lua. Флаг --protected закрывает содержимое файлов. Флаг --maximum закрывает и дополнительно собирает клиентские файлы во внутреннюю программу, которую выполняет GVM, а не обычный CompileString.

Зачем это нужно. Combat.gmod с --protected можно поставить на чужой сервер и всё равно отдавать ему навыки обычными lua-файлами. Владелец сервера меняет урон, не получая исходники расчёта.

Где это встречается на сервере

  • Платный HUD, где тема — контент, а код рисования закрыт.
  • Серверный расчёт урона, который не должен читаться из пакета.

Синтаксис

gincy package build папка --key signer.pem
gincy package build папка --key signer.pem --protected
gincy package build папка --key signer.pem --maximum

Можно добавить --drm, --fingerprint build или recipient, --recipient server.pub.pem, --allow-fallback, --unpack. Эти флаги относятся к политике пакета в сборщике.

Что означает каждая часть

  • --protected — Сервер и клиент помечаются protected. Осмотр пакета показывает PROTECTED и число закрытых записей.
  • --maximum — Оба режима становятся maximum. Клиентские записи могут стать программами GVM. Осмотр показывает MAXIMUM.
  • без флагов — open. Осмотр показывает OPEN, если в манифесте пакета не сказано иное.
  • GVM — Среда, в которой выполняется закрытый клиентский байткод. Диагностика: gincy clientvm status и gincy clientvm profile. Если конструкция Lua не переводится, сборка сообщает GINCY-GVM-UNSUPPORTED.

Что возвращается

Флаги меняют пакет на диске. На уже загруженный модуль они не действуют, пока пакет не поставлен заново.

Что происходит после вызова

Контент в gincy_content этими флагами не закрывается. Возможности, которые модуль открыл контенту, остаются единственной дверью к действиям вроде урона и снаряда. Внутренние таблицы модуля через файл навыка не видны: файл выполняется без глобального Gincy.

Перезагрузка и выгрузка

Смена режима — это новая сборка .gmod, не правка контента.

Ограничения

  • maximum не обещает, что владелец машины не сможет смотреть процесс.
  • Старый закрытый формат v1 команда migrate не превращает в защищённый v2. Нужна сборка из исходников.
  • Код GINCY-GVM-COMPILE значит, что клиентский файл не собрался: в отчёте есть файл и строка.

Рядом обычно вызывают

  • Команды сборки — Куда пишется файл.
  • Контент — Почему навык остаётся открытым.

HUD

ModernHUD.gmod собран с --protected или --maximum.
Он объявляет тип modernhud.config.
Файл темы меняет только поля схемы.
Поле implementation в файле темы не становится методом прокси, если модуль не открыл такую возможность.

Игрок видит тему. Код HUD остаётся в пакете. getmetatable у объекта контента возвращает строку gincy-content, а не внутренние таблицы модуля.
